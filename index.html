Documents & Renewals

Every paper with a date on it — and when each one comes due.

Status rule: overdue is past its date, due soon is within 30 days, current is further out, and no expiry is paper that has no renewal date. Worst first.

Add a document

Name is all it takes — the rest is optional. Leave the date blank for paper with no expiry (a title, a bill of sale): it is kept on file as "No expiry" and the app never invents a renewal date for it. A renewal cost left blank means unknown, not $0.

Summary

Counts by status and the renewal costs you entered. A document with no cost entered has no cost in the totals — the summary counts it as unpriced instead of guessing a price.

Bikes

Bikes live in the shared Pocket Garage roster — the same b1/b2/b3 list the other apps use. Add a bike here and it is added to that roster for every app. There is no delete-bike here: roster management belongs to the landing dashboard, so a mistyped bike is removed there, not here.

Your data

No account, no server, no sync. Your documents live in this browser's local storage. Back them up with Export — one JSON file.

Export

The backup is the whole file — every bike, every document. The per-bike export below is one bike's documents, as JSON or readable plain text.

Import

Import replaces the current file. Export first if you want to keep it. Documents pointing at a bike the shared roster doesn't have yet still load — they show under their roster key until that bike is added.

Try it out

Loads example documents so you can see the overdue, due-soon, current, and no-expiry statuses, and what an unpriced document does to the totals — before entering your own papers. The example dates are relative to today, and the example costs are example costs only.

Delete clears this app's documents only. The shared bike roster is not touched.
